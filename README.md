# ExploreTrends

A cross-platform e-commerce mobile app built with **Expo** and **React Native (Expo Router)**. ExploreTrends demonstrates a full shopping-app UI/UX flow — browsing, categories, cart, wishlist, checkout, and profile management — using a clean, component-based architecture.

## 📱 About the Project

ExploreTrends is a shopping/e-commerce app template. It ships with mock product, cart, category, and user data (`data/*.json`), so the UI is fully explorable out of the box without a backend.

Key screens visible in the app:
- **Home** — hero banner carousel ("Big Sale 70% Off"), popular categories grid (Electronics, Fashion, Home & Garden, Sports, Beauty, Books, Automotive, Toys & Games), and a flash-sale countdown with discounted product cards.
- **Categories/Products** — browsable product grid and listing.
- **Cart** — item list, quantity management.
- **Wishlist** — saved/favorited products.
- **Profile** — edit profile, addresses, payment methods, order history, settings, help & support.
- **Checkout** — order review and payment flow.

## 🚀 Getting Started

**Prerequisites:** Node.js, npm, and the Expo CLI (installed automatically via `npx`).

```bash
# Clone the repo
git clone https://github.com/Manthankhade/ExploreTrends.git
cd ExploreTrends

# Install dependencies
npm install

# Start the development server
npm start        # or: expo start

# Run on a specific platform
npm run android
npm run ios
npm run web
```

## ✨ Features

- Responsive layout logic (small/medium/large device breakpoints) via `AppContext`
- File-based navigation with a 5-tab bottom bar (Home, Categories, Cart, Wishlist, Profile)
- Flash-sale countdown timer and discounted product badges
- Wishlist (favorite) toggling on products
- Full account-management flow: addresses, payment methods, order history, settings
- Works on iOS, Android, and Web from a single codebase
